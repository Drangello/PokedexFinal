# PokédexFinal

Ein interaktiver Pokédex mit Fokus auf Shiny-Pokémon, entwickelt mit HTML, CSS und Vanilla JavaScript.

## Live Demo

[Pokédex öffnen](https://florian-weimann.developerakademie.net/Pokedex/index.html)

## Features

- Pokémon-Daten über die PokeAPI
- Shiny-Sprites
- Pokémon-Suche
- Load-More-Funktion
- Typabhängige Karten
- Diagonale Farbverläufe bei Doppeltypen
- Detailansicht mit Stats, Infos und Evolutionen
- Pokémon-Cries mit Mute-Funktion
- Animiertes Masterball-Loading-Design
- Responsive für Desktop und Mobile

## Tech Stack

- HTML5
- CSS3
- JavaScript
- [PokeAPI](https://pokeapi.co/)

## Über das Projekt

Das Projekt entstand ursprünglich im Rahmen meiner Frontend-Ausbildung und wurde anschließend als eigenes Projekt weiterentwickelt und optisch überarbeitet.
